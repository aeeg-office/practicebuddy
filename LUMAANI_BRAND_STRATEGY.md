# Lumaani — Brand Strategy

**Status:** Approved  
**Date:** 2026-08-21

---

## 1. Brand Name

**Lumaani** (لُمعاني)

The name traces to Persian meaning "elegant, graceful." It also carries natural associations with "luminous," "lumen," and "illumination" — light, clarity, guidance. This dual heritage (MENA origin + universal intelligibility) is the brand's strategic foundation.

### Pronunciation
- English: loo-MAH-nee (لو-ما-ني)
- Arabic: لُمعاني (lumaʿānī)

### Arabic Rendering
**Preferred:** لُمعاني  
**Alternative:** لوماني

## 2. Three-Word Positioning

**Final:**
> Lumaani
> **PRACTICE. LEARN. MASTER.**

*Selected over 25+ candidates for clarity, educational accuracy, memorability, and alignment with the two-attempt pedagogy.*

### How it connects:
- **PRACTICE** — The core action. Students practice skills, attempt questions, engage with content.
- **LEARN** — The teaching outcome. Practice Buddy's two-attempt methodology teaches through mistakes, strategy, and explanation.
- **MASTER** — The goal. Mastery is server-derived, tracked per micro-skill, and drives recommendations.

### Runner-up candidates:
1. DISCOVER. PRACTICE. MASTER.
2. LEARN. GROW. EXCEL.
3. FOCUS. PRACTICE. ACHIEVE.
4. SKILL. STRATEGY. SUCCESS.
5. GUIDED. PRACTICE. MASTERY.

## 3. Brand Personality

| Attribute | Description |
|-----------|-------------|
| **Calm** | The interface disappears behind the learning. No noise, no casino effects. |
| **Clear** | One screen, one task. Everything has a purpose. |
| **Smart** | Modern EdTech with AI-powered question generation and mastery analytics. |
| **Supportive** | Two attempts, strategy, explanation — the product teaches, not just tests. |
| **Credible** | Trustworthy for parents, serious for schools, professional for institutions. |

## 6. Visual Identity Summary

- **Primary color:** Deep navy #1a237e
- **Accent color:** Warm gold #f5a623
- **Logo:** Abstract "L" + light ray — suggesting guidance, growth, and illumination
- **Typography:** System font stack (Inter/Noto for Arabic-ready setup)
- **Style:** Clean, minimal, calm — the interface disappears behind the learning
